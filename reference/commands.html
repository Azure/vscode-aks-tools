Commands

Every command the extension contributes, with where it appears in the tree-view menus.

The menu layout depends on the aks.simplifiedMenuStructure setting, which defaults to true. The Default menu column reflects that default; Classic menu applies when the setting is false. A dash means the command has no entry in that menu and is reachable only from the Command Palette.
